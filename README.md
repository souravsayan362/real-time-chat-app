# Real-Time Chat Application

A real-time chat application built using React, Node.js, Express, and Socket.IO that allows users to communicate instantly with a modern chat interface.

## 🚀 Features

* Real-time messaging using Socket.IO
* User authentication with username input
* WhatsApp-style chat interface
* Message timestamps
* Send messages using Enter key
* Responsive and user-friendly design

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* CSS

### Backend

* Node.js
* Express.js
* Socket.IO
* CORS

## 📂 Project Structure

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/souravsayan362/real-time-chat-app.git
cd real-time-chat-app
```

### 2. Backend Setup

```bash
cd server
npm install
npm start
```

The server will run on:

```
http://localhost:3001
```

### 3. Frontend Setup

Open a new terminal:

```bash
cd client
npm install
npm run dev
```

The frontend will run on:

```
http://localhost:5173
```
